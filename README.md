# Cyrca — Página web

Página web para Cyrca, negocio de limpieza doméstica en Florence, Kentucky (USA) y alrededores.

## Qué es esto

Sitio construido con HTML, CSS y JavaScript "vanilla" (sin frameworks), pensado como proyecto de aprendizaje y como herramienta real de negocio.

## Estructura del proyecto (se va a ir llenando fase a fase)

```
/            → páginas HTML (inicio, servicios, sobre nosotros, contacto)
/css         → estilos
/js          → lógica (calculadora de precios, facturas, formularios)
/img         → imágenes y logo
```
